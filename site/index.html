See what your agent tells the internet.

tattle is a local proxy for Claude Code, Codex and any other coding agent. Run the agent through it and get a report of every outbound request, with API keys, .env values and your personal details flagged by where they went.

One report. Every request, every destination.

When the agent exits, tattle writes a self-contained HTML report: flags first, then each host with what it was sent, then the full request log you can filter. These are real sessions, unedited apart from --share masking.

What gets flagged

tattle scans the path, the query string, every header and the decoded body. A key in an Authorization header is marked expected, because that is how the agent signs in. A key anywhere else is a leak.

Secrets high

  • Provider API keys Anthropic, OpenAI, Google, Hugging Face
  • Cloud and platform tokens AWS, GitHub, Slack, Stripe live
  • Private keys and JWTs PEM blocks, signed tokens
  • .env-style assignments *_KEY= *_TOKEN= *_PASSWORD=
  • Your actual .env values read from the working directory

Personal data med–high

  • Your email global and repo git config
  • Your full name account and git name
  • Login and machine name in headers, paths, queries
  • Home-directory paths /Users/…, /home/…, C:\Users\…
  • Anything you list ~/.tattle/watch.txt

Masked before anything touches disk. The log keeps a key's first four characters and its length, and nothing else.

tattle report --share drops even those and blanks account IDs in paths, so you can post a report without posting your details.

HTTPS without touching your system

Scoped trust

tattle runs mitmproxy with a small addon. Its CA is created in ~/.tattle and never installed system-wide. Only the process you start with tattle run trusts it, through environment variables:

  • HTTPS_PROXY
  • NODE_EXTRA_CA_CERTS
  • SSL_CERT_FILE
  • REQUESTS_CA_BUNDLE
  • CURL_CA_BUNDLE
  • GIT_SSL_CAINFO
  • CODEX_CA_CERTIFICATE

Your browser and every other app are untouched. A client that pins its certificates shows up in the report as a refused connection instead of silently going missing.

Teardown

tattle clean   # deletes ~/.tattle: the CA key and every session

Commands

tattle run -- claude          # run any command through it
tattle run --live -- codex    # stream requests as they happen
tattle tail                   # live view from another terminal
tattle report --open          # open the latest report
tattle report --share         # stricter masking, safe to post
tattle proxy                  # standalone; prints env exports
tattle ls                     # list sessions
Limits
  • HTTP and HTTPS only: not raw TCP, DNS or WebSocket frames.
  • A secret with no recognisable shape, outside your local .env, can slip past the patterns.
  • Localhost traffic bypasses the proxy.
